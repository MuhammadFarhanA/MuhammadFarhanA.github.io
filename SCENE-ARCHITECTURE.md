# Scene architecture

The home route is a continuous vertical narrative:

1. Interface construction — hero, layered architectural panels, and entry points.
2. Identity / system — engineering and creativity as one practice.
3. Career architecture — verified experience entries as timeline stations.
4. Component architecture — verified skills in a modular rack.
5. Digital exhibition — genuine project screenshots and deep links.
6. Quiet editorial — poetry previews and direct poem pages.
7. Architectural reveal — contact and social links with the visual system returning.

Every scene is semantic HTML. The architectural visual is deliberately CSS-native, so the content remains available when WebGL is unavailable and the project avoids a second rendering runtime.
