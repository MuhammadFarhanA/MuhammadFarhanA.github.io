# Design system

- Graphite ink: `#20262b`
- Paper / cream: `#f5f1e9`
- Architectural paper: `#e6e2da`
- Electric blue: `#2459ff`
- Dark graphite: `#1c2227`
- Display: Manrope, with Playfair Display for editorial emphasis
- Technical labels: DM Mono

The system uses thin structural borders, generous whitespace, uppercase technical annotations, deliberate asymmetry, and responsive scene-specific surfaces rather than generic rounded cards.
